# Rotten Potatoes

A Ruby on Rails web application for managing and browsing movies.

## Live Demo

Check out the live application here: [Rotten Potatoes](https://rottenpotatoes-ht-db7f4156db15.herokuapp.com/)

## Features

- Add, edit, and delete movies
- Browse movies by title, rating, and release date
- Supports detailed movie info including director, cast, duration, and description

## Technology Stack

- Ruby on Rails 8.0.3
- PostgreSQL database
- Hosted on Heroku
